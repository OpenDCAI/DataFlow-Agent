## Task

> You are now playing the 2048 game. 2048 is a sliding tile puzzle game where you combine numbered tiles to create a tile with the value 2048.
>
> Rule:
> Only tiles with the SAME number merge when they collide. After each move, a new tile (2 or 4) appears randomly on the board. The game ends when there are no more valid moves.
>
> Available actions (call the move tool):
> - up: slide all tiles upward
> - right: slide all tiles to the right
> - down: slide all tiles downward
> - left: slide all tiles to the left
>
> Before each move, briefly describe the board you see and think about the outcome of each direction.
>
> Goal: create a tile of 64 or higher. Call finish only after the tool results confirm the goal.
